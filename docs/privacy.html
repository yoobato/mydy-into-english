개인정보 안내

이 소개 페이지

로그인, 입력 전송, 광고 또는 분석 추적 스크립트를 포함하지 않습니다. 기능 미리보기는 브라우저에서 미리 작성한 예시를 표시합니다. GitHub Pages에서 호스팅하며, 글꼴을 표시하기 위해 Google Fonts에 연결합니다. 이 과정에서 각 제공자의 정책에 따라 IP 주소 등 일반적인 접속 정보가 처리될 수 있습니다.

iOS 앱

사용자는 자신의 ChatGPT 계정으로 OpenAI에 로그인합니다. 앱은 인증정보를 iOS Keychain에, 대화·저장한 표현·최근 요청 본문을 기기의 앱 저장공간에 보관합니다. AI 요청 시 입력 내용과 필요한 대화 맥락을 OpenAI로 전송합니다. Into English가 운영하는 별도 중계 서버는 없습니다.

앱의 계정 연결 해제는 해당 기기의 로그인 정보를 제거합니다. 같은 계정으로 다시 로그인했을 때 기록을 확인할 수 있도록 기기의 대화 파일은 남습니다. OpenAI 측 데이터 처리와 계정 권한에는 OpenAI의 정책이 적용됩니다.

개발 및 배포 상태

현재 개인 테스트 단계의 앱입니다. 공개 배포 전 데이터 처리와 삭제 기능, 최종 개인정보처리방침을 다시 검토할 예정입니다. 이 페이지는 현재 구현의 안내이며 App Store 등록 완료를 의미하지 않습니다.
