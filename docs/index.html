A FEW DETAILS

궁금한 점

지금 다운로드할 수 있나요?

현재 개인 기기에서 테스트 중이며, App Store와 TestFlight 다운로드 링크는 아직 없습니다. 개발 현황과 실행 방법은 GitHub 저장소에서 확인할 수 있습니다.

ChatGPT 계정이 필요한가요?

실제 iOS 앱의 AI 기능은 본인의 ChatGPT 계정 연결이 필요합니다. 사용 가능 여부와 모델은 계정·워크스페이스의 권한 및 OpenAI 제공 조건에 따라 달라집니다. 이 소개 페이지에는 로그인 기능이 없습니다.

이 페이지에서도 번역할 수 있나요?

위 화면은 미리 작성된 예시로 기능을 설명하는 데모입니다. 실제 AI 번역과 교정은 iOS 앱에서 동작합니다.

소스 코드는 공개되어 있나요?

코드는 GitHub에서 확인할 수 있습니다. 사용·수정·재배포 조건은 저장소의 라이선스 안내를 확인하세요. Into English는 OpenAI의 공식 앱이 아닙니다.
